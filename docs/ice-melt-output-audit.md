# 海冰融化输出与诊断量核对

## 本次新增的当前步融化输出

在实际运行使用的 `namelist.icepack` 的 `nml_list_icepack` 中加入
`'meltb'` 和 `'meltl'`。仓库 `sample_inputs/namelist.icepack` 已启用。

| 配置 ID | NetCDF 变量名 | 数值含义 |
| --- | --- | --- |
| `meltb` | `sea_ice_bottom_melt_step_cat_1` … `_cat_N` | 最近冰步第 n 类的实际底融厚度 `meltbn(:,n)`，单位 m，按该类别冰面积归一化 |
| `meltl` | `sea_ice_lateral_melt_step_cat_1` … `_cat_N` | 最近冰步第 n 类实际侧融体积损失 `meltln(:,n)`，单位 m，按整个网格面积归一化 |

N 为 `ncat`，每个变量均为节点二维场（含时间维）。配置 ID 仍是 `meltb/meltl`；
本次分类输出替代之前的两个总量输出名称。

两者均为融化取正，但面积口径不同。底融直接使用已有的类别冰厚损失诊断；
总底融量需要用底融计算时的类别面积比例加权，不能使用后续重分配后的面积保证精确恢复。
侧融在 `lateral_melt` 中以热量限制后的 `rsiden(n)` 乘侧融执行前的 `vicen(n)` 记录，
因此 `sum(meltln)` 对应该步总侧融 `meltl`（允许浮点求和误差）。它不是浮冰半径缩短量。
如需侧融相对该类别冰面积的等效厚度损失，应除以侧融执行前该类别的面积比例；
不能直接用输出时刻可能已经变化的面积代替。

类别编号对应各融化过程执行时所在的冰厚类别；底融和侧融之间可能发生类别重分配，
同一编号不保证追踪同一批冰。两者不包含底部冻结增长，也不是冰厚总变化。

这些变量由 `init_history_therm` 在每次冰过程开始时清零，然后由热力学过程填充。
`step_icepack` 以 `ice_dt = dt * nstep_ice` 为时间步执行。输出使用现有 SCHISM
`nspool` 时次，直接保存当前值，不做输出间隔累计，也不在输出后清零。
相邻输出可能跳过若干冰步，也可能重复同一冰步的值；只有确认每个冰步恰好取到一次时才能求和。
单步平均融化速率为输出值除以 `ice_dt`（m/s）。

`writeout_nc` 根据变量名动态定义 NetCDF 变量；分类诊断在旧有 300 槽位块之后
分别保留 `ncat` 个槽位，使用稳定基址，不受旧有 ridging 分支修改 `noutput` 的影响。
现有通用写出函数没有单位参数，因此单位与时间语义在这里及源码注释中记录。

## 原需求表的覆盖情况

以下区分当前可读取/重建的数据与仍需新增的预算诊断。所有可选输出都需在运行配置中启用；
同名变量必须核对实际传入数组，不能只相信旧字段名。

| 类别 | 当前可输出或间接计算 | 仍缺少的部分 |
| --- | --- | --- |
| 温度 | `Tsfcn` 实际为 `sstn`：第 1 项开放水面，第 n+1 项第 n 类冰下 SST；海洋 SST 取 SCHISM 节点 `temp` 最上层 | 面积加权类别 SST 可计算，但不能直接假定等于海洋 SST，尤其需匹配更新时刻 |
| 冰状态 | `aice0/aicen/vicen/aice/vice`；类别厚度为 `vicen/aicen`，冰覆盖区平均厚度为 `vice/aice`，`vice` 是网格等效厚度 | 除法需排除零/极小冰面积；当前示例未启用 `aicen/vicen` |
| 混合参数 | `vvel` 实际为 β，`uvel` 实际为代表半径；κe 在 `icedrv_transfer.F90` 中为 54；时间步来自配置；相对速度可用 `ICE_velocity` 和最上层 `hvel` 计算 | 当前示例未启用 β/半径；速度需匹配耦合时刻，理想化实验在传入混合计算时将冰速和海流置零 |
| 水层与冰点 | `hmix=min(max(0,dp+eta2),abs(znl(nvrt)-znl(nvrt-1)))` 可用水深、水位、`zcor` 重建；`sss` 取最上层节点 `salt`；按实际 `tfrz_option` 调用同一冰点公式 | `hmix/Tf/sss` 本身未由 `icedrv_io` 输出；冰盐度 `sice/sicen` 不能代替海水盐度 |
| 底融 | 本次 `meltb` 输出当前步各类别实际底融厚度 `meltbn` | 未输出独立底融热量和输出间隔累计值；净冰海热通量不能等同于纯底融耗热 |
| 侧融 | 本次 `meltl` 输出当前步各类别实际侧融量 `meltln` | 未单独输出侧融耗热及输出间隔累计值；严格耗热涉及被融化冰雪的焓，不能由融化体积唯一恢复 |
| 热量输入与交换 | SCHISM 有 `ICE_net_heat_flux` 和部分表面热通量；重启动保存 `hocnn_old/fswthrun_old` | 缺少进入指定水层的完整离散热输入、海洋输运/混合及各过程累计预算；重启动快照不等于时间累计 |
| 储热与调整 | 同时刻的水层厚度、温度、面积及一致热容常数可估算储热和端点差 | 缺少重分配、限幅等各过程前后能量诊断，端点差无法唯一分解过程贡献 |

若用相对冰点储热 `rho*c_p*h*(T-Tf)`，冰点变化本身也影响差值；
应与使用固定参考温度的储热预算区分。类别储热还必须使用对应时刻的面积比例。

结论：状态量与大部分混合参数可读取或重建；本次补上当前步底融、侧融量。
原表仍未全部覆盖，严格的融化耗热、区间累计及能量调整需要在计算过程内新增诊断。
